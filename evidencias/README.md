## Como adicionar as evidências originais (opcional)

1. No computador em que o laboratório foi executado, localize os arquivos gerados com `Tee-Object` (caso existam) e as capturas de tela reais.
2. No GitHub, abra este diretório e utilize **Add file → Upload files**.
3. Envie somente arquivos autênticos, por exemplo `teste-01.txt`, `teste-02.txt` e imagens `.png` criadas durante a atividade.
4. Confira se os dados desses arquivos correspondem aos valores registrados. Caso haja divergência, corrija o relatório usando as evidências originais.
5. Não publique dados pessoais, tokens ou caminhos sensíveis eventualmente presentes nas capturas.

**Não foram criados logs brutos, capturas de tela nem arquivos de saída fictícios.**
